## Decisiones tomadas (y por qué)
- **Unidad de "Volumen dólar linked": nominal, NO "M USD"** — verificado con un `curl` real a
  `data912.com/live/arg_notes`: el campo `v` da magnitudes (ej. D31L6 → 110.064.471) del mismo
  orden que `q_bid`/`q_ask` (cantidades/nominal en pesos, no dólares — los linked cotizan en pesos
  contra el TC oficial). Mezclarlo en la tabla "Vol. (M USD)" de MAE hubiera sido un número
  falso/engañoso. Se etiquetó honestamente como "M (nominal)", aparte de esa tabla, como su propia
  línea KPI junto al oficial mayorista.
- **También se limpió el texto técnico de la nota de `bcra-mulc-chart.tsx`**, no solo del
  `¿Qué es esto?` como decía literalmente el punto 36 — mismo texto exacto ("BCRA API v4 (variable
  78…)"), pero ahí estaba a la vista SIEMPRE (footnote de tabla, no colapsable), así que dejarlo
  sin tocar hubiera sido peor que el problema original que el punto pedía resolver.

## Trampas descubiertas (para la próxima sesión)
- **Playwright + entrada en cascada (fade+rise) del rediseño premium**: con `waitForTimeout(500)`
  sin `reducedMotion`, un screenshot puede capturar un elemento a mitad de animación de opacidad →
  se ve como un hueco en blanco donde debería haber contenido (pasó con la 1ª tira de KPIs de
  "Compras netas BCRA" en mobile). No es un bug de layout: con `reducedMotion:"reduce"` +
  `waitForTimeout(900)` el mismo elemento renderiza completo. Para verificación visual futura,
  usar `reducedMotion:"reduce"` de entrada evita este falso positivo.
- **Playwright global, no instalado como dependencia del proyecto**: `node_modules/playwright` no
  existe en este repo; el sandbox lo tiene instalado global en
  `/opt/node22/lib/node_modules/playwright`. Un `import ... from "playwright"` en un script ESM
  falla con `ERR_MODULE_NOT_FOUND` (NODE_PATH no alcanza para resolución ESM de specifiers
  desnudos) — hay que importar por **ruta completa** al `index.mjs` del paquete global.
- **`npm run start` sirve el build viejo si se edita código después de buildear**: al arreglar la
  nota técnica de `bcra-mulc-chart.tsx` DESPUÉS de haber levantado el server, el screenshot seguía
  mostrando el texto viejo — hubo que matar el proceso, `rm -rf .next && npm run build` de nuevo, y
  recién ahí levantar el server para que el fix se viera. Nada nuevo (ya documentado en sesiones
  anteriores), pero volvió a pasar acá.
